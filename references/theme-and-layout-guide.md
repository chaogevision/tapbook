# 绘本主题与页面布局规范

## 目标

阅读器共享一套稳定的沉浸式绘本舞台。Skill 随附横屏与竖屏通用柔彩背景，并内置冬日、交通、工程、海洋、森林、农场、太空和故事花园等主题场景。每本书先根据整本 PDF 自动预选一个内置场景；阅读者可以在页面主题菜单中手动切换，也可选择本书专属背景（若已提供）。背景提供氛围，不替代、重绘或遮挡 PDF 原画。网页用 HTML/CSS 搭建有封面、纸页层、书脊和投影的 2.5D 书本；PDF 页面图作为书页显示，不能把整本书或书页交给图像生成器重画。阅读器必须在没有网络连接时正常显示全部已打包的背景。

## 主题分析

在写入 `book.json` 前，检查封面、书名、故事文字、至少三张有代表性的内页和整本书反复出现的视觉元素。不要只凭书名或单页决定主题。选择最能概括整本书的一个主主题，并在 `readerTheme.reason` 用一句话记录依据。

允许使用的主题预设：

| preset | 适用内容 | 舞台氛围 |
| --- | --- | --- |
| `winter` | 冬天、雪、冰、节日 | 冰蓝天空、雪坡、少量雪花和雪人 |
| `vehicles` | 交通工具、出行、道路 | 天空蓝、柔和道路、通用小车或路标 |
| `construction` | 工程车、建筑、工地 | 沙色与天蓝、简化吊臂、工程车和安全锥 |
| `ocean` | 海洋、海边、水下动物 | 青绿渐层、浪花、气泡和通用小鱼 |
| `forest` | 森林、野生动物、自然探索 | 叶绿与草地、树冠、落叶或花朵 |
| `farm` | 农场、田园、农作物 | 草坡、田地、栅栏、谷仓和叶片 |
| `space` | 太空、行星、宇航探索 | 柔和星空、行星和星点 |
| `storybook` | 主题混合、证据不足或不适合其他主题 | 柔和纸艺色块、圆点和星星，不放具体场景物件 |

`source` 设为 `auto` 表示由 Skill 根据 PDF 判断，`user` 表示使用者指定，`fallback` 表示证据不足时采用通用主题。高置信度才自动使用具象装饰；低置信度使用 `storybook`，不要猜测书中没有的场景。每本书先选一个稳定的主主题，避免每翻一页就整体换肤。只有场景转换明显且与故事相关时，才可给单页加入小型场景点缀；颜色、书页质感和底栏样式仍保持一致。

## 图片与装饰规范

- 主视觉始终是 PDF 原始页图，按原始宽高比完整显示；禁止裁切、拉伸、描摹、补画或覆盖原书文字和插图。
- 主题装饰放在书页后方或舞台边缘。全出血页面没有空白边时，装饰只能留在页面后方，不得压在原画上。
- 九种预设（柔彩舞台、故事花园、冬日雪原、交通小镇、工程工地、海底世界、森林漫步、田园农场、星际探险）都配有独立的横屏和竖屏插画背景，存放在 `themes/backgrounds/<preset>-landscape.webp` 与 `themes/backgrounds/<preset>-portrait.webp`。主题菜单图标使用 SVG；阅读舞台背景使用真实位图插画，不用 SVG 绘制。
- 分析完封面、故事内容和代表性内页后，把最合适的预设写入 `readerTheme.preset`。阅读器首次打开时直接显示该场景；读者可以在绘本页的场景菜单中切换到柔彩舞台或其他主题。选择按书保存在当前浏览器中。
- 专属背景是可选项。只有当前 Agent 能生成图像、且书的主题适合定制时，才制作主题背景，放在 `assets/` 并将 `readerTheme.backgroundImage` 设为相对路径；只有单张横图无法适配竖屏时，再提供 `readerTheme.backgroundImagePortrait`。生成能力不可用时保留默认背景并继续，不得阻断流程。
- 背景建议宽幅 3:2 或 16:10，分辨率足以覆盖常见桌面和平板屏幕。主体装饰沿边缘分布，书本所在的中央区域留白、低对比度，底部可有前景地面/雪坡/草坡来承托书本。
- 图像生成提示词应根据本书主题、色彩、季节和重复场景具体编写。明确要求“只画环境背景；中心区域留空；不要书、纸页、文字、标志、按钮、UI、角色、仿画原书插画”。禁止让模型生成或重绘原书中的页面内容。
- 生成环境图后检查主题与整本书相符、无伪文字/标志/意外角色、中央阅读区足够干净。导出为优化后的本地 JPEG 或 WebP，避免把 PNG 原始大图直接塞进 ZIP；离线包必须包含该图。
- 页面首次打开默认使用 PDF 分析选出的内置场景。页眉主题菜单列出全部内置场景；存在自定义背景时，也显示“本书专属背景”。选择按书保存在本地。自定义图加载失败时回退到本书自动匹配的内置主题。
- 内置背景加载失败时回退到故事花园的横屏/竖屏插画，并用 CSS 色板保持控件可读。是否制作专属背景不影响书本结构、阅读和离线播放。
- 主题物件只作氛围提示：不进入单词热点、不承载必须阅读的信息、不遮挡翻页触控区。
- 保持正文和朗读控件对比度；高亮同时使用形状/底色变化，不能只靠颜色表达状态。动效轻柔，尊重 `prefers-reduced-motion`。
- 所有素材使用相对本地路径，限制背景文件体积，不加载 CDN、在线字体或运行时图片生成服务。

### 生成提示词结构

先用整本书的主题分析填写方括号，再生成背景，不要只替换书名：

> 为儿童互动绘本阅读器生成一张【横版 3:2】的环境背景。主题是【主题】，主要场景/季节是【从封面和至少三张内页观察到的共同元素】，主色是【配色】。画面采用【插画/纸艺/柔和 2.5D】风格；【树、云、山、海浪、行星等通用环境装饰】沿四周和角落分布，底部有【承托书本的地面/雪坡/草坡等】。画面中央约 60% 区域保持明亮、干净、低细节，供网页叠放原书页面。只生成环境，不要书、书页、文字、标志、UI、按钮、原书角色或仿画原书插图。

如果确需竖屏版，使用同一世界观和配色，改成【竖版 2:3】；让关键主题物件留在竖屏可见的边缘，中央继续为原书页面留空。不要简单裁剪横版图来冒充竖版构图。

## 页面排版判断

检查 PDF 每页尺寸、页面图和阅读顺序，再设置 `presentation.pageMode`：

- `single`：页面是海报、拼贴或跨页会打乱原始阅读顺序时，单页显示。
- `facing-pages`：PDF 每页是一张独立的书页时使用。宽屏横向平板将连续故事页组成左右跨页；封面、书名页、封底/尾页保持单页。手机竖屏和窄窗口自动退回单页。
- `source-spread`：PDF 的每个文件页本身已经是一整张双页扫描时使用；每个文件页仍完整显示，禁止再次拼页。

宽屏跨页按原 PDF 页序相邻组合，书页热点坐标仍以各自原图为基准。若页面尺寸或阅读顺序不确定，设为 `single` 并在交付说明中标明，不要仅凭页面宽高比猜成跨页扫描。

## 输出前检查

在手机竖屏、平板竖屏和 iPad 横屏预览。确认自动预选的主题正确、主题菜单中的内置场景可切换；若含自定义背景，确认可选择它并能回到内置场景。确认语速选择能影响单词、单句、本页和整本的本地音频；单句前后切换可用；本页和整本的逐页英中模式都按“本页英语、同页中文、下一页英语、下一页中文”的顺序播放，停止按钮会取消剩余队列。确认 2.5D 书本边缘和阴影可见、原画无裁切或遮挡、跨页顺序正确、词语热点仍贴合页面、底栏不盖住书页，并且所有内置及可选专属背景都包含在离线包中。主题或排版判断不确定时，使用通用柔彩舞台和单页模式，保留人工可改的 `readerTheme` 与 `presentation` 字段。
